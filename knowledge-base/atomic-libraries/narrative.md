# 叙事数据库（Narrative Database）

> 原子库 · 共 40 条（宏观结构12 + 中观桥段16 + 微观技巧12）｜ 故事怎么搭、怎么抓人、怎么留余味。
> 供模块1（小说创作）、模块3（NLC剧本编译）、模块7B（幕评师）调用。

## 字段格式
名称(中/英) / 层级 / 核心机制 / 节拍或要点 / 情绪曲线 / 适用题材·篇幅 / 经典案例 / 常见陷阱 / 可组合 / 应用示例

## 一、宏观结构（1–12）

**1. 三幕结构 Three-Act**
- 层级：宏观｜机制：建置→对抗→结局
- 节拍：第一幕(铺垫+激励事件)→第二幕(冲突升级+中点+至暗)→第三幕(高潮+结局)
- 情绪曲线：平→起伏攀升→谷底→高峰→落定
- 适用：几乎一切，长片/短剧通用｜陷阱：第二幕注水拖沓
- 可组合：救猫咪/英雄之旅是其细化｜示例：标准电影骨架

**2. 英雄之旅 Hero's Journey**
- 层级：宏观｜机制：平凡世界→冒险召唤→试炼→深渊重生→携宝归来
- 节拍：12阶段(召唤/拒绝/导师/越界/盟友敌人/磨难/奖赏/归途/重生/回归)
- 情绪曲线：安逸→不安→挣扎→死而复生→升华
- 适用：奇幻/冒险/成长｜陷阱：套用僵硬显公式化
- 可组合：嵌入三幕｜示例：少年成长为英雄

**3. 救猫咪节拍 Save the Cat**
- 层级：宏观｜机制：15个精确节拍卡点(按页码/时间)
- 节拍：开场画面→主题陈述→铺垫→推动→争论→第二幕→B故事→玩乐→中点→坏人逼近→一无所有→灵魂黑夜→第三幕→结局→终场画面
- 情绪曲线：精密的波峰波谷
- 适用：商业类型片/短剧｜陷阱：机械卡点失去灵气
- 可组合：三幕的工业细化｜示例：好莱坞类型片

**4. 七点结构 Seven-Point**
- 层级：宏观｜机制：从结局倒推七个支点
- 节拍：钩子→第一情节点→第一收紧→中点(被动转主动)→第二收紧→第二情节点→结局
- 情绪曲线：双向收束至中点转折
- 适用：悬疑/类型小说｜陷阱：中点不力则塌
- 可组合：与角色弧光对齐｜示例：主角中点由被动转主动

**5. 起承转合 Kishōtenketsu**
- 层级：宏观｜机制：东方四段，·不依赖冲突，靠"转"制造新意
- 节拍：起(引入)→承(展开)→转(意外视角/并置)→合(收束统合)
- 情绪曲线：平稳→延展→惊奇→回味
- 适用：文艺/生活流/东方叙事/短片｜陷阱：西方观众觉"没冲突"
- 可组合：适合无反派的温情题材｜示例：日常中一个转念

**6. 五幕结构 Five-Act (Freytag)**
- 层级：宏观｜机制：金字塔——铺垫/上升/高潮/下降/结局
- 节拍：introduction→rising→climax(正中)→falling→catastrophe
- 情绪曲线：对称金字塔
- 适用：悲剧/戏剧/史诗｜陷阱：高潮居中后半易松
- 可组合：莎剧式｜示例：古典悲剧

**7. 非线性叙事 Nonlinear**
- 层级：宏观｜机制：打乱时间顺序重组
- 节拍：按主题/悬念而非时间排列
- 情绪曲线：靠剪辑制造悬念与顿悟
- 适用：悬疑/文艺/烧脑｜陷阱：为乱而乱让观众迷失
- 可组合：+多线/闪回｜示例：拼图式揭示真相

**8. 多线叙事 Multi-thread / Hyperlink**
- 层级：宏观｜机制：多条故事线并行最终交汇
- 节拍：各线独立推进→交叉→汇合
- 情绪曲线：分散张力→汇聚爆发
- 适用：群像/史诗/犯罪｜陷阱：线索过多稀释，主线不清
- 可组合：+交叉剪辑｜示例：数条命运在一点相撞

**9. 环形结构 Circular / Ring**
- 层级：宏观｜机制：结尾呼应开头，首尾闭环
- 节拍：开场意象→历程→回到起点(但已质变)
- 情绪曲线：宿命轮回的余味
- 适用：文艺/宿命主题｜陷阱：呼应生硬显刻意
- 可组合：+母题重复｜示例：结尾重现开场画面，意义已变

**10. 倒叙结构 Reverse Chronology**
- 层级：宏观｜机制：从结果倒推原因
- 节拍：结局先行→逐步回溯成因
- 情绪曲线：已知结局，看"为何如此"的悲凉
- 适用：悬疑/悲剧/实验｜陷阱：缺悬念动力
- 可组合：+戏剧反讽｜示例：先看悲剧再揭因

**11. 三一律 Classical Unity**
- 层级：宏观｜机制：时间/地点/情节统一(一天/一地/一事)
- 节拍：高度集中的单一连续事件
- 情绪曲线：密闭压力锅式持续紧张
- 适用：密室/舞台剧/独幕｜陷阱：场景单一易闷
- 可组合：+倒计时｜示例：一个房间一晚的对峙

**12. 单元剧/章回体 Episodic**
- 层级：宏观｜机制：相对独立的单元串成整体
- 节拍：每集自成起承转合+贯穿主线
- 情绪曲线：单元小波+主线大弧
- 适用：剧集/网文/系列短剧｜陷阱：主线太弱沦为流水账
- 可组合：每单元内嵌三幕｜示例：单元案件+长线悬念

## 二、中观桥段（13–28）

**13. 钩子开场 Cold Open / Hook**｜中观｜开篇即抛悬念/奇观/强情绪抓住观众｜前3句/前30秒定生死｜适用全部，短剧尤甚｜陷阱：钩子与正文脱节
**14. 激励事件 Inciting Incident**｜中观｜打破主角日常、推其入局的事件｜通常第一幕末｜陷阱：来得太晚开篇拖沓
**15. 第一情节点 Plot Point 1**｜中观｜主角下决心、无法回头，进入第二幕｜适用类型片｜陷阱：主角被动则无力
**16. 中点 Midpoint**｜中观｜·重大转折/真相，主角由被动转主动或镜像反转｜居故事正中｜陷阱：中点平淡=全片塌腰
**17. 一切尽失 All is Lost / 灵魂黑夜**｜中观｜第二幕末主角跌至谷底、希望破灭｜情绪最低点｜陷阱：不够低则高潮不爽
**18. 高潮 Climax**｜中观｜最终对决，主线矛盾总爆发解决｜第三幕｜陷阱：铺垫不足或反高潮
**19. 反转 Twist**｜中观｜颠覆认知的揭示，意料之外情理之中｜需前文埋线｜陷阱：为转而转/无伏笔=耍赖
**20. 伏笔与回收 Setup & Payoff**｜中观｜前埋细节后兑现，制造"原来如此"｜贯穿全篇｜陷阱：埋而不收/收得突兀
**21. 契诃夫之枪 Chekhov's Gun**｜中观｜出现的关键道具必须起作用｜强调"不必要的细节就删"｜陷阱：摆了枪却没开
**22. 红鲱鱼 Red Herring**｜中观｜故意误导的假线索｜悬疑必备｜陷阱：误导过头观众受骗感
**23. 麦高芬 MacGuffin**｜中观｜推动剧情的"目标物"，本身可不重要｜驱动追逐｜陷阱：观众不在乎它则失效
**24. 闪回 Flashback**｜中观｜插入过去揭示动机/真相｜需清晰进出信号｜陷阱：滥用打断节奏
**25. 平行蒙太奇 Parallel Montage**｜中观｜两事并置剪辑制造对比/张力｜如营救vs危机｜陷阱：两线不相关则散
**26. 最后一分钟营救 Last-Minute Rescue**｜中观｜倒计时下千钧一发的拯救｜高潮常用｜陷阱：太套路缺新意
**27. 双重反转 Double Twist**｜中观｜反转之后再反转｜烧脑悬疑｜陷阱：为炫技牺牲情感
**28. 开放结局 Open Ending**｜中观｜不给明确答案，留想象｜文艺/悬疑｜陷阱：与"没写完"混淆惹观众怒

## 三、微观技巧（29–40）

**29. 章末钩子 Cliffhanger**｜微观｜段落/章节结尾留悬念逼人追看｜网文/剧集命脉｜陷阱：注水钩子骗点击
**30. 戏剧反讽 Dramatic Irony**｜微观｜观众知道而角色不知，制造揪心/喜剧｜陷阱：用错场合失效
**31. 悬念vs惊吓 Suspense vs Surprise**｜微观｜·希区柯克炸弹论:让观众预先知道有炸弹=持续悬念；突然炸=短暂惊吓｜悬念更高级
**32. 潜文本 Subtext**｜微观｜台词表面一套、真意一套，"说的不是想的"｜高级对白｜陷阱：全说白=无回味
**33. 展示而非告知 Show Don't Tell**｜微观｜用动作细节代替直白陈述情绪｜与微表情/动作库联动｜陷阱：旁白替代表演
**34. 三次法则 Rule of Three**｜微观｜事物出现三次(铺垫-强化-爆发/笑点)｜喜剧与节奏｜陷阱：超三次冗余
**35. 对比/对位 Juxtaposition**｜微观｜并置反差元素强化主题｜如喜丧并置｜陷阱：生硬拼贴
**36. 母题/主导动机 Motif/Leitmotif**｜微观｜反复出现的意象/音乐绑定情感｜增强统一与回味｜陷阱：重复无变化变啰嗦
**37. 误会法 Misunderstanding**｜微观｜信息差制造冲突或喜剧｜爱情/喜剧｜陷阱：一句话能解的误会拖太久惹烦
**38. 身份错位 Mistaken Identity**｜微观｜认错人/伪装制造戏剧｜喜剧/悬疑｜陷阱：逻辑漏洞
**39. 倒计时/时限 Ticking Clock**｜微观｜设定时间压力逼出紧张｜动作/灾难｜陷阱：时限不可信则无压力
**40. 不可靠叙述者 Unreliable Narrator**｜微观｜叙述者隐瞒/扭曲，结尾揭穿｜悬疑/心理｜陷阱：欺骗与误导界限，需公平给线索

## 使用提示
- **选结构速记**：商业类型→救猫咪/三幕；成长冒险→英雄之旅；东方文艺无强冲突→起承转合；烧脑→非线性/七点+双重反转；群像→多线；剧集网文→单元体+章末钩子。
- **抓人三件套**：钩子开场(13)+章末钩子(29)+悬念(31)——短剧留存率核心。
- **反转铁律**：反转(19)必须靠伏笔(20)/契诃夫之枪(21)支撑，否则=耍赖（模块7B幕评师会扣分）。
- **与编译器联动**：NLC剧本编译(模块3)按本库结构切节拍；幕评师(模块7B)用本库检查"结构是否塌腰、反转是否有铺垫"。
- 共 **40 条**：宏观12 + 中观16 + 微观12。
