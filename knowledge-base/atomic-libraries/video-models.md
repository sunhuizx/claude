## 一、国内模型

### 1. 可灵 Kling 3.0
- **厂商：** 快手（Kuaishou）
- **版本：** 3.0 系列（2026 年初发布，承接 O1 / 2.6）
- **最大时长：** 单段约 3–15 秒，支持续接
- **分辨率·帧率：** 原生 4K（非放大）、最高 60fps
- **核心能力：** 文生视频 / 图生视频 / 参考生成 / 视频编辑；**原生音频**（多语言/方言）、**主体一致性控制**、对口型、**首尾帧**、多镜头
- **提示词语法特点：** 结构化「主体+动作+环境+运镜+光线」效果好；中文理解强；运镜词敏感
- **擅长：** 运动真实感、人物面部一致性、国产题材、写实短剧
- **短板：** 复杂多人交互偶有穿帮；超长叙事需分段
- **推荐场景：** 国产短剧、写实人物剧、需要角色全片一致的项目
- **提示词技巧：** 用「角色形象卡」固定外貌串复用；首尾帧功能分别写首帧/尾帧图提示词保证衔接
- **费用：** 积分制（按时长/分辨率计）
> 资料来源（已改写以符合授权要求）：[Kling 官方指南](https://app.klingai.com/global/blog/kling-video-3-0-ai-director-features-guide)、[Kling 3.0 评测](https://overchat.ai/ai-hub/kling-3-0)

### 2. 即梦 Seedance（字节跳动）
- **厂商：** 字节跳动 / BytePlus（即梦为消费端 App，Seedance 为模型）
- **版本：** Seedance 2.0（2026-02 爆火）/ 1.0 / 1.0 Pro / Lite
- **最大时长：** 多段多镜头叙事，单段秒级
- **分辨率·帧率：** 480p / 720p / 1080p
- **核心能力：** 文生视频 / 图生视频 / **原生多镜头叙事**、平滑运动转场、多风格、对口型
- **提示词语法特点：** 对「上下文线索 + 细微动作」响应好；适合口语化、情境化描述
- **擅长：** 多镜头连贯叙事、平滑运动、批量出片、低成本
- **短板：** 极致电影质感略逊海螺；2.0 海外发布因版权争议曾暂停（以官方为准）
- **推荐场景：** 需要大量分镜、低成本快速迭代的短剧/口播/带货
- **提示词技巧：** 多给情境与连续动作线索，少堆砌镜头术语
- **费用：** 1.0 约 $0.03/s(480p)、$0.07/s(720p)、$0.12/s(1080p)，主打降本
> 资料来源（已改写）：[Seedance vs Hailuo](https://www.edenai.co/post/seedance-1-0-pro-vs-hailuo-best-ai-video-generator-in-2026-eden-ai-copy)、[Seedance 定价](https://www.runcomfy.com/ja/playground/bytedance/seedance-1-0)

### 3. 海螺 Hailuo 02
- **厂商：** MiniMax（稀宇科技）
- **版本：** Hailuo 02
- **最大时长：** 秒级单段，主打质感
- **分辨率·帧率：** 高清，电影级渲染
- **核心能力：** 文生视频 / 图生视频、**高级导演控制**、强物理运动
- **提示词语法特点：** 需要明确「意图 + 镜头语言(lens language) + 氛围」，吃专业术语
- **擅长：** 电影级真实感、物理运动、镜头美学
- **短板：** 提示词门槛高（需懂镜头语言）；批量效率不如 Seedance
- **推荐场景：** 单条高质量电影感镜头、关键高光镜头
- **提示词技巧：** 写清景别+焦段+运镜+光线+氛围，越专业越出彩
- **费用：** 积分制
> 资料来源（已改写）：[Seedance vs Hailuo 对比](https://blog.segmind.com/seedance-ai-video-generator/)

- **提示词语法特点：** 支持主体库引用保证一致性；可结构化描述
- **擅长：** 音画一体化成片、MV、角色一致性、性价比
- **短板：** 极致写实略逊顶级模型
- **推荐场景：** 需要「画面+声音」一次成片、MV、数字人口播
- **提示词技巧：** 建好主体库再生成，跨镜头角色才稳定
- **费用：** 约 $0.07/s(360-540p)，720-1080p 约 2.2 倍
> 资料来源（已改写）：[Vidu Q3 介绍](https://techpilot.ai/tools/vidu-most-cost-effective-ai-video-generator/)、[Vidu 官方文档](https://platform.vidu.cn/docs/one-click-ai-mv)

- **推荐场景：** 复杂剧情段落、概念片、叙事驱动
- **提示词技巧：** 用完整场景叙事描述，而非关键词堆砌

- **推荐场景：** 专业后期、需要精修可控的镜头
- **提示词技巧：** 必给起始参考图；用其运动控制工具调运镜
