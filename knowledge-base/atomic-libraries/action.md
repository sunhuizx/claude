# 动作数据库（Action Database）

> 原子库 · 共 70 条 ｜ 动作是"可拍的情绪载体"——把心理活动外化成镜头能拍到的身体动作。
> 本库供模块4（提示词生成器）调用；`音效联动` 字段直通声音系统（模块6），实现画面=声音同步。

## 字段格式
```
动作名称 / 分类 / 身体部位分解 / 力度·速度 / 情绪含义 /
推荐镜头(景别+角度) / 音效联动 / 视觉关键词 / 风险·穿帮提示 / 适配题材
```

## 分类
- **日常**(1–20)：生活化动作 ｜ **情绪外化**(21–38)：把心理转成动作
- **互动**(39–56)：人与人 ｜ **战斗**(57–70)：动作/打斗

# 一、日常动作（1–20）

## 1. 行走
- **分类：** 日常
- **身体部位分解：** 双腿交替迈步、手臂自然摆动、躯干随步伐微起伏、视线平视
- **力度·速度：** 中速平稳（可调：闲庭信步/匆忙快走）
- **情绪含义：** 中性，速度与姿态透露心境（拖沓=疲惫，大步=自信）
- **推荐镜头：** 全景/中景，平移跟拍或反向跟拍
- **音效联动：** 脚步声（鞋型+地面材质）、衣物摩擦
- **视觉关键词：** walking, steady gait, arms swinging naturally, tracking shot
- **风险·穿帮：** AI 易出"滑步/腿穿模"；步频与速度要匹配
- **适配题材：** 通用

## 2. 奔跑
- **分类：** 日常
- **身体部位分解：** 大幅摆臂、躯干前倾、双腿大步蹬地、呼吸急促肩起伏
- **力度·速度：** 高速、爆发
- **情绪含义：** 紧迫、逃离、追赶、急切、兴奋
- **推荐镜头：** 中景跟拍/侧移横移、手持增临场
- **音效联动：** 急促脚步、喘息、心跳、风声
- **视觉关键词：** running, sprinting, leaning forward, fast tracking, motion blur
- **风险·穿帮：** 速度感不足显假；背景需快速后移
- **适配题材：** 动作、追逐、青春、灾难

## 3. 坐下
- **分类：** 日常
- **身体部位分解：** 屈膝、躯干后倾下沉、手扶椅/桌、臀部着座
- **力度·速度：** 慢（疲惫瘫坐）至快（赌气坐下）
- **情绪含义：** 放松、疲惫、谈话开始、泄气
- **推荐镜头：** 中景，平视
- **音效联动：** 椅子吱呀、衣物声、呼气
- **视觉关键词：** sitting down, lowering into chair, settling
- **风险·穿帮：** 着座点与椅子错位穿模
- **适配题材：** 通用

## 4. 起身
- **分类：** 日常
- **身体部位分解：** 手撑、腿发力蹬直、躯干上抬前倾
- **力度·速度：** 缓（虚弱）至猛（拍案而起）
- **情绪含义：** 决心、警觉、离开、激动
- **推荐镜头：** 中景/全景，可仰角增气势
- **音效联动：** 椅子推响、衣物、呼吸
- **视觉关键词：** standing up, rising from seat, pushing up
- **风险·穿帮：** 重心转换不自然
- **适配题材：** 通用

## 5. 喝水 / 饮酒
- **分类：** 日常
- **身体部位分解：** 手握杯举至唇、头微仰、喉结滚动吞咽、放下
- **力度·速度：** 慢品至猛灌
- **情绪含义：** 平静/借酒消愁/豪饮/紧张润喉
- **推荐镜头：** 近景/特写
- **音效联动：** 吞咽声、杯子落桌、液体声
- **视觉关键词：** drinking, raising glass to lips, gulping, throat moving
- **风险·穿帮：** 杯中液面/手指穿模
- **适配题材：** 生活、情感、黑帮

## 6. 进食
- **分类：** 日常
- **身体部位分解：** 持餐具、送入口、咀嚼、吞咽
- **力度·速度：** 细嚼至狼吞虎咽
- **情绪含义：** 享受/饥饿/敷衍/食不知味
- **推荐镜头：** 近景，可俯拍食物
- **音效联动：** 咀嚼声、餐具碰碗、汤汁声
- **视觉关键词：** eating, chewing, bringing food to mouth
- **风险·穿帮：** 嘴部与食物对位、筷子穿模
- **适配题材：** 生活、美食、家庭

## 7. 抽烟

- **风险·穿帮：** 烟雾飘向不自然、烟头长度跳变
- **适配题材：** 黑帮、文艺、悬疑、年代

## 8. 开门

# 二、情绪外化动作（21–38）

## 21. 哭泣
- **分类：** 情绪外化
- **身体部位分解：** 泪流、肩颤抖、掩面或仰头、抽噎、揉眼
- **力度·速度：** 隐忍啜泣至失声痛哭
- **情绪含义：** 悲伤、委屈、释放、绝望
- **推荐镜头：** 特写（隐忍）/全景（崩溃瘫坐）
- **音效联动：** 抽噎、哽咽、吸鼻、压抑呜咽
- **视觉关键词：** crying, tears streaming, shoulders shaking, sobbing, covering face
- **风险·穿帮：** 泪痕生成不自然
- **适配题材：** 情感、悲剧

## 22. 大笑
- **分类：** 情绪外化
- **身体部位分解：** 张嘴露齿、头后仰、肩抖、拍腿/捂肚、眼眯
- **力度·速度：** 中至剧烈
- **情绪含义：** 喜悦、畅快、嘲讽（狂笑）、癫狂
- **推荐镜头：** 中景/近景
- **音效联动：** 笑声（爽朗/狂躁/冷笑）
- **视觉关键词：** laughing, head thrown back, shoulders shaking with laughter
- **风险·穿帮：** 笑声与口型不同步
- **适配题材：** 喜剧、情感、反派

## 23. 颤抖
- **分类：** 情绪外化
- **身体部位分解：** 手抖、唇颤、肩抖、腿软、牙关打颤
- **力度·速度：** 细微至剧烈
- **情绪含义：** 恐惧、寒冷、愤怒压抑、虚弱、激动
- **推荐镜头：** 特写手/脸
- **音效联动：** 牙齿打颤、急促呼吸、物体被抖响
- **视觉关键词：** trembling, shaking hands, quivering lips, shivering
- **风险·穿帮：** 抖动幅度过规律显假
- **适配题材：** 恐怖、悲剧、惊悚

## 24. 摔砸物品
- **分类：** 情绪外化
- **身体部位分解：** 抓起、抡臂、奋力掷出、物体碎裂
- **力度·速度：** 爆发、快
- **情绪含义：** 暴怒、崩溃、宣泄、失控
- **推荐镜头：** 中景，跟随抛物，可慢动作
- **音效联动：** 碎裂声、撞击、回响
- **视觉关键词：** throwing object, smashing, shattering, hurling in rage
- **风险·穿帮：** 碎裂物理、碎片轨迹
- **适配题材：** 家庭冲突、犯罪、情感

## 25. 捶墙 / 砸桌
- **分类：** 情绪外化
- **身体部位分解：** 握拳/张掌、抡起、猛击表面、震动
- **力度·速度：** 爆发
- **情绪含义：** 愤怒、悔恨、无力、强调
- **推荐镜头：** 近景手部+面部反应
- **音效联动：** 重击声、桌面震动、物件跳动
- **视觉关键词：** punching wall, slamming fist on table, pounding surface
- **风险·穿帮：** 击打无震动反馈显假
- **适配题材：** 冲突、犯罪、情感

## 26. 瘫坐

- **身体部位分解：** 腿软下滑、背靠墙/物、四肢无力垂落、头低垂

## 使用提示
- **动作=可拍的情绪**：心理活动（如"他很绝望"）必须翻译成本库的具体动作（如"瘫坐+抱头"），与表演微表情库配合使用。
- **音效联动**：每条的 `音效联动` 直接交给声音系统（模块6）排音效，实现"画面动作=声音"同步。
- **力度/速度是情绪开关**：同一动作（如坐下），缓慢=疲惫、猛然=赌气，靠力度速度区分情绪。
- **组装镜头时**：动作 +「景别 + 运镜 + 灯光 + 构图」共同构成完整镜头；战斗动作优先配合慢动作/冲击帧与子弹时间。
- 本库共 **70 条**：日常20 + 情绪外化18 + 互动18 + 战斗14。
