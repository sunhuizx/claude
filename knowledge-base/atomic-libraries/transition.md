# 转场数据库（Transition Database）

> 原子库 · 共 38 条 ｜ 转场决定"镜头之间怎么接"，是节奏与情绪流动的关节。
> 供模块4、模块5调用；`衔接要求` 对接模块4 首尾帧校验——服务于"上段尾帧=下段首帧"。

## 字段格式
转场名称 / 类型(剪辑·视觉·声音·逻辑) / 实现原理 / 衔接要求(首尾帧·方向·光线) / 情绪节奏作用 / 适用场景 / 经典案例 / 视觉关键词 / 风险提示
⭐ = 对"尾帧↔首帧"方向/运动/构图要求最严，AI 生视频段间衔接重点。

## 一、剪辑类（1–10）
1. 硬切 Hard Cut｜剪辑｜两镜直接拼接｜守180°轴线、换景别角度｜利落明快(最常用)｜常规叙事/正反打｜风险:同机位小幅会变跳切
2. 跳切 Jump Cut｜剪辑｜同机位删时间｜机位不变主体略移｜时间压缩/焦躁/风格化｜Vlog/慌乱｜风险:滥用显廉价
3. ⭐匹配剪辑 Match Cut｜剪辑｜尾帧首帧形状相似借形过渡｜尾帧主体形状位置≈首帧｜诗意/时空跨越/隐喻｜大跨度时间｜风险:对不齐则失效
4. ⭐动作衔接 Cut on Action｜剪辑｜动作中切机位｜动作方向速度跨镜连续｜流畅无感｜起身/开门/拿物｜风险:速度不连贯会顿
5. 交叉剪辑 Cross-cut｜剪辑｜多线索反复切换｜各线内部连贯+渐快｜悬念/紧张/双线张力｜营救与危机｜风险:线索过多迷失
6. J-Cut｜声音｜下镜声音先入｜声音提前0.5-2s｜预告/引导｜场景过渡｜风险:进太早困惑
7. L-Cut｜声音｜前镜声音延续｜画面切后声音再延0.5-2s｜情绪延续/余韵｜对话反应镜头｜风险:过长拖节奏
8. 叠化 Dissolve｜剪辑｜前隐后显短暂重叠｜两镜亮度色调相近｜时间流逝/回忆/柔和｜抒情蒙太奇｜风险:滥用显老气
9. 淡入淡出 Fade｜剪辑｜从黑/白渐显或渐隐｜用于段落首尾留停顿｜章节感/起始终结｜开篇结尾｜风险:频繁割裂节奏
10. 闪白/闪黑 Flash｜剪辑｜极短几帧纯白/黑插入｜配冲击音效瞬间完成｜冲击/震惊/闪回触发｜爆炸/枪击/创伤｜风险:频闪光敏安全

## 二、视觉类（11–20）
11. 划像 Wipe｜视觉｜边界划过推走前镜｜划动方向呼应运动｜复古/分段｜复古风/章节｜风险:写实剧显出戏
12. ⭐图形匹配 Graphic Match｜视觉｜相似形状颜色构图重合｜尾帧首帧图形位置形状重合｜隐喻/联想｜概念关联｜风险:对位不准失效
13. ⭐遮挡转场 Object Wipe｜视觉｜物体扫过遮黑换场｜遮挡物运动方向跨镜连续｜无缝/隐形穿越｜空间穿越｜风险:速度方向不连贯露馅
14. ⭐甩镜转场 Whip Pan｜视觉｜极速甩模糊中切同向甩入｜前镜甩出方向=后镜甩入方向｜高能/急促/活力｜动作快节奏｜风险:方向不一致会撞
15. ⭐出入画 Exit/Enter Frame｜视觉｜主体走出边缘下镜对应边缘走入｜出画方向=入画来向｜空间连续/行进感｜人物移动｜风险:方向反则像跳轴
16. 旋转转场 Spin｜视觉｜旋转模糊后切同向停下｜旋转方向速度一致｜眩晕/时空翻转/华丽｜穿越/回忆｜风险:易眩晕
17. 缩放/推进 Zoom Punch-in｜视觉｜急推某点后切场｜推入终点呼应下镜首帧｜进入内心/强调｜进回忆/梦境｜风险:推入点不当突兀
18. 模糊转场 Blur｜视觉｜失焦模糊中切再合焦｜失焦程度衔接自然｜入梦/恍惚/醉酒｜意识模糊｜风险:丢信息慢节奏
19. 光效转场 Light Leak｜视觉｜强光斑扫过覆盖切换｜光斑最亮瞬间切｜温暖/唯美/怀旧｜回忆/广告/青春｜风险:严肃题材不搭
20. ⭐穿黑转场 Pass-through Dark｜视觉｜穿入纯黑/遮挡物全黑瞬间换场穿出｜穿入方向=穿出方向,全黑帧作切点｜沉浸/无缝穿越｜长镜感转场｜风险:全黑时长把握

## 三、声音类（21–22）
21. 声音桥 Sound Bridge｜声音｜连续声音横跨两场缝合画面｜声音连续不断画面其下切换｜连贯/关联/暗示因果｜场景过渡/蒙太奇｜风险:需情绪呼应或反差
22. 音乐转场/卡点 Music-Driven｜声音｜剪辑点卡音乐节拍重音｜切点对齐beat随乐句切｜律动/燃/爽感｜MV/混剪/高燃｜风险:卡点不准泄气

## 四、逻辑类（23–25）
23. 主题/概念转场 Thematic Match｜逻辑｜靠概念含义相关过渡｜概念关联清晰｜对照/讽刺/升华｜对比蒙太奇｜风险:太隐晦get不到
24. 时间流逝/蒙太奇 Time-lapse｜逻辑｜快剪或延时压缩时间｜元素渐变体现时间推进｜压缩时间/成长/变迁｜训练成长/岁月｜风险:缺情绪线变流水账
25. 闪回/梦境转场 Flashback/Dream｜逻辑｜视觉声音信号标记进入回忆梦境｜进出用一致信号包裹+回忆调色区分｜揭示过去/内心/虚实｜回忆杀/创伤｜风险:进出信号不一致分不清时空

## 五、数字/现代/短视频类（26–38）
26. 故障转场 Glitch｜视觉·数字｜信号故障/像素撕裂/RGB错位闪切｜故障帧瞬间切,可叠错位抖动｜数字感/科技/赛博/躁动不安｜科幻/赛博/电音MV/潮流｜风险:滥用显廉价+光敏安全
27. 数据流溶解 Datamosh｜视觉·数字｜帧间压缩破坏致像素拖拽溶解｜两镜运动方向相近,像素流向延续｜迷幻/数字溶解/超现实｜实验/电音MV/赛博｜风险:难控,过度成噪点
28. ⭐变速甩入 Speed Ramp｜视觉·数字｜慢动作骤然加速甩入下镜(升格转场)｜加速甩出方向=下镜甩入方向｜燃/爽/动感顿挫｜运动/卡点/Vlog/混剪｜风险:速度曲线生硬则泄气
29. ⭐缩放模糊 Zoom Blur｜视觉·数字｜径向缩放模糊冲入/拉出切场｜缩放中心点呼应下镜焦点｜冲击/进入/眩晕推进｜短视频/MV/进场｜风险:中心偏移致眩晕
30. 硬切爆点 Smash Cut｜剪辑｜情绪/音量极端反差的突兀硬切｜尾帧首帧强反差(动静·响静)｜惊吓/反差/黑色幽默｜恐怖/喜剧反差｜风险:无铺垫显突兀
31. 虹膜转场 Iris｜视觉｜圆形光圈收缩/扩张露出下镜｜圆心对准焦点主体｜复古/聚焦/卡通收尾｜默片/卡通/复古｜风险:现代写实易出戏
32. ⭐形变转场 Morph｜视觉·数字｜前镜形状液态形变流入后镜｜形变起止形状/位置衔接｜奇幻/魔法/流体/无缝｜奇幻/广告/科技｜风险:形变不自然显假
33. 3D立方/翻页 3D Cube·Page Turn｜视觉·数字｜画面作3D立方旋转/翻页换面｜翻转方向连贯｜数字/活泼/相册感｜电子相册/活泼短片｜风险:模板感廉价慎用
34. ⭐无缝隐形剪辑 Invisible Cut｜剪辑｜借遮挡/摇过/同色面藏剪辑点伪长镜｜遮挡物/同色面/运动跨镜完全连续｜一镜到底/沉浸/炫技｜伪长镜/沉浸叙事｜风险:对位露馅则破功
35. 信号干扰/坏轨 Signal Distortion｜视觉·数字｜雪花/扫描线/VHS坏轨卷动切换｜干扰最强帧切｜复古录像/监控/诡异｜年代录像/恐怖/纪实｜风险:过度致噪难看
36. 像素化溶解 Pixelate｜视觉·数字｜画面像素化/马赛克化再解析出下镜｜像素化最强瞬间切｜数字/游戏/8bit复古｜游戏/科技/复古｜风险:像素感不搭写实
37. ⭐遮罩擦除 Masked Reveal｜视觉·数字｜形状遮罩(文字/图形)擦出下镜｜遮罩运动方向/形状衔接｜设计感/品牌/MG动画｜片头/广告/MG动画｜风险:过度设计抢戏
38. RGB分离/色差 Chromatic Split｜视觉·数字｜RGB三通道错位分离闪切｜错位方向呼应运动｜故障美学/冲击/电音潮流｜电音MV/赛博/潮流｜风险:光敏+廉价感

## 使用提示
- 衔接铁律对接模块4：⭐转场对"尾帧↔首帧"方向/运动/构图要求最严，首尾帧校验优先核对。
- 节奏选转场速记：动作→硬切/动作衔接/甩镜/卡点；抒情回忆→叠化/模糊/光效；悬念→交叉剪辑/声音桥；时空跨越→匹配剪辑/图形匹配/穿黑。
- AI生视频：段间衔接优先用动作衔接/出入画/遮挡/甩镜（靠运动连续），把前段尾帧状态写进后段首帧提示词；叠化/淡入淡出可后期合成。
- 共38条：剪辑10 + 视觉10 + 声音2 + 逻辑3 + 数字/现代13。
- 数字/现代类多为后期合成/特效实现，AI生视频常需借后期工具(剪辑软件/AE)叠加；其中⭐(变速甩入/缩放模糊/形变/无缝隐形剪辑/遮罩擦除)对首尾帧运动/形状衔接要求严。
- 短视频(抖音/快手/Reels)高频：变速甩入·缩放模糊·故障·甩镜·卡点·无缝隐形剪辑——节奏快、卡点强、炫技感足。
