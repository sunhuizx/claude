# 影视 AI 智能体 · 专家知识库（Knowledge Base）

本知识库是「专家级影视 AI 智能体」的领域大脑。所有提示词模块（小说创作 / NLC 剧本编译器 / 提示词生成器 / 分镜 / 检查 / 声音 等）在运行时**调用**本库的条目，保证全流程术语统一、风格可控、输出专业。

---

## 一、双层架构

```
第一层  原子库 (atomic-libraries/)   ——「构件」，讲单一知识点
            │  被调用、组装成
第二层  成品镜头库 (shot-libraries/) ——「菜谱」，可直接用的完整镜头方案
```

## 五、设计原则
- 景别/角度/构图为"维度速查"，交叉索引静态/运动库，零重复。
- 情绪/主观/群像/环境/特效/动漫为"内容型"，全字段新建，每条标注"组装来源"便于溯源。
- 跨媒介覆盖：图片拍摄 / 短视频 / 长视频 / 纪录片(历史记录) / 电影 / 短剧 / 连续剧 / 宣传MV。
- 视频模型数据库基于 2026 年公开资料核实。
