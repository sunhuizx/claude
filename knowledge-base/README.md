# 影视 AI 智能体 · 专家知识库（Knowledge Base）

本知识库是「专家级影视 AI 智能体」的领域大脑。所有提示词模块（小说创作 / NLC 剧本编译器 / 提示词生成器 / 分镜 / 检查 / 声音 等）在运行时**调用**本库的条目，保证全流程术语统一、风格可控、输出专业。

---

## 一、双层架构（已与用户确认 · 决策点1）

```
第一层  原子库 (atomic-libraries/)   ——「构件」，讲单一知识点
        视频模型 / 表演微表情 / 灯光 / 构图 / 运镜 / 动作 / 转场 / 导演风格 / 叙事
            │  被调用、组装成
            ▼
第二层  成品镜头库 (shot-libraries/) ——「菜谱」，讲一个可直接用的完整镜头
        13 个子库，每条用统一的 18 字段格式
```

> 通俗讲：原子库是「食材」（一种光、一个构图、一种运镜），成品镜头库是「菜谱」（把食材组合成一个可直接拍 / 可直接喂 AI 的镜头）。互不重复、可复用、好维护。

---

## 二、成品镜头库 · 18 字段格式（已确认 · 决策点2 加第18项）

```
1. 镜头名称        2. 镜头分类        3. 核心目的        4. 镜头轨迹
5. 画面变化        6. 主体关系        7. 情绪效果        8. 节奏属性
9. 适用场景        10. 不适用场景     11. 经典案例       12. 导演意图
13. 常用组合       14. 风险提示       15. 推荐时长       16. 适配题材
17. 视觉关键词     18. 适配视频模型   ← 标注可灵/即梦/Runway 哪个生成此镜头最佳
```

## 四、使用约定

- 每个条目都是结构化字段，便于程序解析与 RAG 检索。
- 「视觉关键词」字段直接对接提示词生成器（模块4），是出图/出视频的最终素材。
- 「适配视频模型」字段对接视频模型数据库，确保镜头用最合适的模型生成。
- 库内信息会随模型迭代更新；视频模型数据库已基于 2026 年公开资料核实。
