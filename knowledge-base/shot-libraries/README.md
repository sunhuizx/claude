# 成品镜头库（Shot Libraries · 第二层）

> 用第一层原子库（灯光/构图/运镜/微表情/动作/转场/导演/叙事/视频模型）组装成"可直接用的完整镜头方案"。
> 编号规则：SC-1xx 静态 / SC-2xx 运动 / SC-3xx 景别 / SC-4xx 角度 / SC-5xx 构图 / SC-6xx 情绪 / 后续主观/群像/环境/特效/动漫。

## 统一字段格式（23 字段）
```
编号 / 镜头名称 / 镜头分类 / 景别与机位 / 焦段建议 / 核心目的 / 镜头轨迹 /
画面变化 / 主体关系 / 情绪效果 / 节奏属性 / 光线与色彩 / 适用场景 / 不适用场景 /
经典示例画面 / 导演意图 / 常用组合 / 首帧态→尾帧态 / 风险提示 / 推荐时长 /
适配题材 / 视觉关键词 / AI生成提示词 / 适配视频模型 / 声音音效线索
```

## 设计原则
- 景别/角度/构图为"维度速查"，交叉索引静态/运动库，零重复。
- 情绪/主观/群像/环境/特效/动漫为"内容型"，全字段新建。
- 每条情绪/内容镜头标注"组装来源"，便于溯源与维护。
