## SC-101 正面单点透视居中构图镜头
- 镜头分类：固定 / 透视 / 中轴对称
- 景别与机位：全景至大全景；摄影机严格居中于空间中轴线，水平正对纵深；透视线汇聚于画面正中单一消失点
- 焦段建议：超广角18–24mm（汇聚急剧，库布里克语法）/ 24–35mm更克制
- 核心目的：以最纯粹单点透视居中把空间几何秩序推向极致，赋予绝对权威/对称/不可撼动稳定，消失点=叙事最高权重位
- 镜头轨迹：完全静止（任何运动都会破坏透视精确性）
- 画面变化：纵向线条向中心汇聚；中心主体因汇聚获极强视觉权重；纵深处元素渐小制造强烈纵深
- 主体关系：消失点即权力点——置于消失点的主体自动获得空间赋予的最高叙事权威
- 情绪效果：权威、秩序、强迫感、对称压迫美、仪式感、不可逃脱的方向性
- 节奏属性：建筑秩序型静止节奏，画面本身即宣言
- 光线与色彩：冷调对称布光(顶光或两侧对称壁灯)，低饱和强秩序(恐怖向加幽绿惨白)
- 适用场景：权力空间(走廊/法庭/宫殿)、强迫性叙事方向、走向命运节点、库布里克对称美学
- 不适用场景：有机自然环境、快节奏追逐、需不稳定感的心理叙事
- 经典示例画面：《闪灵》酒店走廊、《全金属外壳》军营走廊
- 导演意图：库布里克——所有线条汇于一点，观众眼睛无法不跟随，是视觉强制，是权力最纯粹的空间化表达
- 常用组合：建立透视→人物从消失点走来(权力逼近)/走向消失点(走向命运死亡)/静止→轻微推入
- 首帧态→尾帧态：空走廊纯几何对称(无人) → 人物抵达消失点占据权力位(下段首帧接此人物特写)
- 风险提示：机位水平仪精校绝对居中；两侧对称误差毁效果；焦距决定汇聚速度；AI易两侧不对称/墙面扭曲需"perfectly symmetrical"锁参考图
- 推荐时长：3–12秒
- 适配题材：惊悚/权力/建筑美学/心理
- 视觉关键词：#单点汇聚 #中轴权威 #透视强制 #几何秩序 #库布里克语法
- AI生成提示词：`one-point perspective, perfectly symmetrical corridor, central vanishing point, converging lines, wide-angle deep space, static locked camera, cold symmetrical lighting, Kubrick style, authoritative, unsettling order, cinematic 4k`
- 适配视频模型：可灵(对称纵深稳)>即梦>Runway(参考图定对称)
- 声音音效线索：低频环境嗡鸣+脚步回响渐近

## SC-102 中轴对称舞台式静帧
- 镜头分类：固定 / 对称构图
- 景别与机位：中景至全景，机位居中、与被摄面平行（正面平拍）
- 焦段建议：35–50mm（减畸变，保平面舞台感）
- 核心目的：用左右镜像对称制造秩序、强迫、仪式，画面像工整舞台画
- 镜头轨迹：完全静止
- 画面变化：几乎无；靠主体微动作或"对称中的一处打破"成为焦点
- 主体关系：主体居正中或左右等量分布；对称中的不对称元素=戏剧重点
- 情绪效果：工整、强迫、荒诞幽默、距离感、掌控
- 节奏属性：静止陈述型，画面即态度
- 光线与色彩：均匀正面光，高饱和撞色或统一色板(韦斯·安德森式)
- 适用场景：人物登场、群体合影式、荒诞喜剧、强迫秩序世界观
- 不适用场景：纪实手持、需纵深临场感的动作
- 经典示例画面：韦斯·安德森《布达佩斯大饭店》正面对称构图
- 导演意图：用对称把现实"扁平化"成画框，制造童话/疏离的作者印记
- 常用组合：对称静帧 → 90°快速摇/横移到下一个对称画面
- 首帧态→尾帧态：构图一致，仅主体表情/小动作变化
- 风险提示：对称误差极易被察觉需精确居中；背景杂乱会毁工整
- 推荐时长：2–6秒
- 适配题材：文艺/喜剧/童话/广告
- 视觉关键词：#中轴对称 #舞台扁平 #安德森式 #撞色工整
- AI生成提示词：`perfectly symmetrical centered composition, frontal flat tableau, Wes Anderson style, pastel symmetrical color palette, static locked camera, whimsical, deadpan, cinematic`
- 适配视频模型：可灵>即梦（避免大运动模型）
- 声音音效线索：安静环境+节拍式配乐（强化工整荒诞）

## SC-103 固定大远景定场
- 镜头分类：固定 / 定场
- 景别与机位：大远景，机位远而高或平，环境为主、人如点
- 焦段建议：广角16–35mm
- 核心目的：交代时空、规模与氛围，建立故事世界第一印象
- 镜头轨迹：完全静止（让观众自由扫视环境）
- 画面变化：几乎无；可有自然元素动态(云/车流/人流)增添生气
- 主体关系：人物渺小，被环境包裹，凸显人与世界的关系
- 情绪效果：壮阔、孤独、渺小、史诗、宁静
- 节奏属性：呼吸式停顿节奏，给观众"安顿"时间
- 光线与色彩：自然光(黄金时刻/蓝调最佳)，大色块氛围
- 适用场景：开场、转场、章节起始、交代新地点
- 不适用场景：紧凑对话、需聚焦表情的情绪戏
- 经典示例画面：维伦纽瓦《沙丘》渺小人影对巨大沙漠
- 导演意图：先给世界，再给人——空间即叙事的前提
- 常用组合：大远景定场 → 切入全景/中景逐步靠近主体
- 首帧态→尾帧态：构图稳定，自然元素轻微流动 → 切入主体
- 风险提示：缺主体或视觉焦点易沦为空洞风景；AI远景人物易糊
- 推荐时长：3–8秒
- 适配题材：史诗/科幻/文艺/公路/灾难
- 视觉关键词：#定场 #大远景 #人渺小 #史诗环境
- AI生成提示词：`extreme wide establishing shot, vast landscape, tiny human figure for scale, golden hour, atmospheric depth, static camera, epic cinematic 4k`
- 适配视频模型：可灵/Veo(航拍定场强)>即梦>Luma
- 声音音效线索：环境氛围声(风/城市/自然)+史诗配乐铺底

## SC-104 固定情绪特写
- 镜头分类：固定 / 特写
- 景别与机位：特写至大特写，机位平视、与眼睛同高
- 焦段建议：85mm（背景虚化、五官不变形）
- 核心目的：把全部注意力压在一张脸上，捕捉最细微的情绪流动
- 镜头轨迹：完全静止（不抢戏，让表演说话）
- 画面变化：背景大虚化；变化全在微表情(眼神/嘴角/呼吸)
- 主体关系：单人独占画面，观众被迫直视其内心
- 情绪效果：亲密、揪心、压迫、共情、无处可逃
- 节奏属性：静止凝注，节奏由表演内在张力决定
- 光线与色彩：伦勃朗光或柔侧光，低饱和，暗背景突出脸
- 适用场景：情绪高点、独白、隐忍、聆听反应、抉择瞬间
- 不适用场景：需交代环境/动作的场面、群戏
- 经典示例画面：是枝裕和式克制的人物近距凝视
- 导演意图：相信演员的脸——一个微表情胜过千言旁白
- 常用组合：中景对话 → 切固定特写(情绪爆发) → L-cut声音延续
- 首帧态→尾帧态：构图不变，表情由克制→流露(如眼眶渐红)(供切反应镜)
- 风险提示：AI易五官漂移/换脸，必须锁角色形象卡；背景别穿帮
- 推荐时长：3–7秒
- 适配题材：情感/悲剧/文艺/悬疑
- 视觉关键词：#情绪特写 #微表情 #浅景深 #平视凝注
- AI生成提示词：`locked-off emotional close-up, 85mm shallow depth of field, subtle micro-expressions, glistening eyes, Rembrandt soft light, dark background, static camera, cinematic`
- 适配视频模型：可灵(面部一致性最佳)>Runway(参考图)
- 声音音效线索：环境静音+呼吸声放大（接微表情库与模块6）

## SC-105 过肩对话固定镜
- 镜头分类：固定 / 过肩
- 景别与机位：中近景，越过一人肩膀拍对面，守180°轴线
- 焦段建议：50–85mm（自然透视，前景肩适度虚化）
- 核心目的：建立两人对话的空间与关系张力，是对话戏的支柱镜
- 镜头轨迹：完全静止（正反打交替时各自固定）
- 画面变化：焦点人物表情变化；前景肩头作稳定框
- 主体关系：前景肩=参照与压迫，焦点人物居三分线承载信息
- 情绪效果：对话感、对峙、关系张力、临场
- 节奏属性：随对白节奏切换正反打，单镜内静止
- 光线与色彩：常规三点布光，按场景定调
- 适用场景：对话、谈判、审讯、对峙、表白
- 不适用场景：独角戏、大场面、需运动的追逐
- 经典示例画面：谈判桌上的正反打过肩
- 导演意图：用"谁的过肩占得多"暗示权力关系与视角倾向
- 常用组合：过肩A → 反打过肩B → 双人镜/特写强调；可配J/L-cut
- 首帧态→尾帧态：机位固定，焦点人物说话/反应(供切反打)
- 风险提示：切反打勿越轴(否则空间错乱)；前景肩占比别过大挡视线
- 推荐时长：2–6秒/镜
- 适配题材：通用/犯罪/情感/职场
- 视觉关键词：#过肩 #正反打 #对话张力 #守轴线
- AI生成提示词：`over-the-shoulder shot, foreground shoulder soft focus, subject on third line, 50mm, three-point lighting, static camera, conversation tension, cinematic`
- 适配视频模型：可灵>即梦>Runway
- 声音音效线索：对白为主+室内环境底噪


## SC-106 顶视俯拍静帧(上帝视角)
- 镜头分类：固定 / 极端俯角
- 景别与机位：全景，机位正上方90°垂直俯拍
- 焦段建议：广角24–35mm（纳入图案化布局）
- 核心目的：以全知上帝视角把场面图案化，赋予宿命、抽离、设计感
- 镜头轨迹：完全静止（图案的工整需要静止）
- 画面变化：主体在平面上的位置关系即叙事；可对称/几何排布
- 主体关系：人物被"压平"成图案元素，强调命运被俯视、被安排
- 情绪效果：宿命、渺小、抽离、秩序美、上帝视角的冷静
- 节奏属性：静止凝视，超然节奏
- 光线与色彩：均匀顶光，可强对比地面图案
- 适用场景：尸体/床戏/布局展示、命运感、设计美学、转场
- 不适用场景：需面部情绪、纵深临场的戏
- 经典示例画面：俯拍躺地人物形成的几何构图
- 导演意图：把人放进"棋盘"，宣告其被更高力量俯视与摆布
- 常用组合：顶视静帧 → 切平视特写(从被俯视到主观)
- 首帧态→尾帧态：构图稳定，主体微动(供接降机位或切平视)
- 风险提示：纯俯视缺面部信息靠位置关系叙事；AI顶视人体易畸形
- 推荐时长：3–8秒
- 适配题材：悬疑/心理/犯罪/艺术/文艺
- 视觉关键词：#上帝视角 #顶视俯拍 #图案化 #宿命
- AI生成提示词：`top-down god's eye view, directly overhead 90 degrees, flat-lay geometric composition, symmetrical staging, static camera, fatalistic, cinematic`
- 适配视频模型：可灵/Luma>Veo
- 声音音效线索：低频持续音/留白静默（强化超然感）

## SC-107 低角度仰拍权威静帧
- 镜头分类：固定 / 仰角
- 景别与机位：中景至全景，机位低、向上仰拍主体
- 焦段建议：广角24–35mm（夸张高大感与压迫纵深）
- 核心目的：让主体在画面中显得高大、强势、不可挑战
- 镜头轨迹：完全静止
- 画面变化：主体高耸压向镜头；天花板/天空入画增压迫
- 主体关系：观众被置于"被俯视"的弱势位，主体获权威
- 情绪效果：威严、压迫、强势、英雄感或威胁感
- 节奏属性：静止震慑型
- 光线与色彩：可配顶/逆光勾勒轮廓，冷硬或英雄暖调
- 适用场景：反派登场、权威宣告、英雄高光、审判者
- 不适用场景：需平等对话、亲密柔和的戏
- 经典示例画面：仰拍登场的反派/王者
- 导演意图：用机位高度直接编码权力——低机位=主体强
- 常用组合：仰拍权威 → 反打俯拍弱势者(权力对比)
- 首帧态→尾帧态：固定，主体微动/俯视镜头(供接弱势反打)
- 风险提示：过度广角仰拍会变形显滑稽；需配合体态与光
- 推荐时长：2–6秒
- 适配题材：动作/犯罪/英雄/权力/奇幻
- 视觉关键词：#仰拍 #低角度 #权威压迫 #高大
- AI生成提示词：`low-angle shot looking up, towering imposing subject, wide angle, ceiling or sky in frame, dramatic rim light, static camera, powerful, intimidating, cinematic`
- 适配视频模型：可灵>即梦>海螺
- 声音音效线索：低沉压迫配乐/脚步沉重回响

## SC-108 前景框架式静帧(框中框)
- 镜头分类：固定 / 框架式构图
- 景别与机位：中景至全景，机位透过门/窗/拱/缝隙拍主体
- 焦段建议：35–50mm（前景框与主体层次清晰）
- 核心目的：用画面内的"内框"聚焦主体，制造窥视、囚禁或舞台隔离感
- 镜头轨迹：完全静止
- 画面变化：内框稳定不动，主体在框内活动
- 主体关系：主体被框"困住"或被"凝视"，框=观察者/牢笼/隔阂
- 情绪效果：窥视、囚禁、隔离、聚焦、私密、被监视
- 节奏属性：静止凝视型
- 光线与色彩：框内外明暗差强化(框暗主体亮)
- 适用场景：囚禁、窥视、隔阂、偷看、舞台式聚焦
- 不适用场景：开阔自由的情绪、快节奏动作
- 经典示例画面：透过门框/窗框凝视屋内人物
- 导演意图：用框暗示"被困/被看"，让构图本身讲心理状态
- 常用组合：框架式静帧 → 推入/切特写(突破框=突破处境)
- 首帧态→尾帧态：内框固定，主体微动(供接穿过框进入下一空间)
- 风险提示：内框勿喧宾夺主；框与主体要有意义关联，否则只是噱头
- 推荐时长：3–7秒
- 适配题材：悬疑/文艺/爱情/心理/惊悚
- 视觉关键词：#框中框 #前景框架 #窥视 #囚禁感
- AI生成提示词：`frame within a frame, shooting through a doorway/window, subject framed in interior frame, foreground darker than subject, static camera, voyeuristic, cinematic depth`
- 适配视频模型：可灵>即梦>Runway
- 声音音效线索：环境隔音感/偷窥时压低的呼吸

## SC-109 镜像倒影静帧
- 镜头分类：固定 / 镜像构图
- 景别与机位：近景至全景，机位固定捕捉镜面/水面/玻璃中的倒影
- 焦段建议：35–85mm（视空间，保证实体与倒影清晰或有取舍）
- 核心目的：用倒影制造双重、内省、虚实或身份分裂的隐喻
- 镜头轨迹：完全静止
- 画面变化：实体与倒影同步微动，二者对照
- 主体关系：实体+镜像并置——真实自我 vs 内心/伪装/另一面
- 情绪效果：内省、双重、虚实、分裂、梦境、孤独
- 节奏属性：静止凝思型
- 光线与色彩：可借镜面反光制造层次，冷调或暧昧
- 适用场景：内心独白、身份主题、整理仪容、悬疑虚实、双面人
- 不适用场景：需明确单一焦点的动作、群戏
- 经典示例画面：镜中与现实的双重自我对望
- 导演意图：用倒影外化"人有两面"——看到的与隐藏的
