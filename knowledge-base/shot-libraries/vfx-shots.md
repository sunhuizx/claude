## SC-1001 爆炸冲击波
- 镜头分类：特效 / 爆炸
- 景别与机位：全景/中景，机位略低或侧，可配急推/震动
- 焦段建议：广角24–35mm（纳入爆炸规模与冲击）
- 核心目的：呈现爆炸的火光、冲击波、碎片与震撼，制造危机与视觉高潮
- 镜头轨迹：固定+机震/急推/缓退避险；可配升格慢动作
- 画面变化：火球膨胀 → 冲击波扩散 → 碎片飞溅 → 烟尘弥漫
- 主体关系：爆炸即危机，人物常在前景被冲击波掀飞/扑倒
- 情绪效果：震撼、危机、暴力、灾难、肾上腺素
- 节奏属性：瞬间爆发型（或升格慢放放大）
- 光线与色彩：爆炸橙红强光、火光映照、烟尘
- 适用场景：战争、爆破、灾难、动作高潮、车爆/楼炸
- 不适用场景：安静文艺/室内小场景
- 经典示例画面：人物前景，背后建筑爆炸火球升腾(不回头走开)
- 导演意图：用爆炸的火光与冲击波把危机推向视觉顶点
- 常用组合：爆炸 → 升格慢动作(SC-224)人物前景/冲击波掀飞 → 烟尘中起身
- 首帧态→尾帧态：引爆瞬间 → 火球烟尘扩散(供切人物反应/狼藉)
- 风险提示：AI爆炸火焰/碎片物理易假，宜慢放+烟尘+火光映照增真实；勿强求精细碎片
- 推荐时长：2–5秒
- 适配题材：战争/动作/灾难/犯罪/科幻
- 视觉关键词：#爆炸 #冲击波 #火球 #碎片烟尘
- AI生成提示词：`massive explosion, expanding fireball, shockwave, flying debris, smoke and dust, fiery glow, slow motion optional, cinematic 4k`
- 适配视频模型：可灵>即梦>海螺
- 声音音效线索：爆炸轰鸣+冲击低频+耳鸣+碎片落地
- 🔗组装来源：运镜SC-224升格/SC-222急推+灯光SC-35闪烁火光+情绪SC-601恐惧

## SC-1002 变身/变形
- 镜头分类：特效 / 变身变形
- 景别与机位：中景/特写，机位固定或缓推，聚焦变形过程
- 焦段建议：50–85mm（突出变形细节）
- 核心目的：呈现角色/物体的变身、变形、形态转换的奇观
- 镜头轨迹：固定或缓推/环绕，强调变形主体
- 画面变化：形态渐变/迸裂重组/能量包裹后蜕变(人→兽/老→幼/形态切换)
- 主体关系：变身即"蜕变/失控/觉醒"，形态变化承载剧情转折
- 情绪效果：震撼、诡异、觉醒、失控、神性或恐怖
- 节奏属性：渐变蜕变型，可慢放强调
- 光线与色彩：变身能量光/迸裂光，诡异或神圣色
- 适用场景：超能觉醒、狼人/怪物变身、魔法变形、衰老/返老
- 不适用场景：写实日常
- 经典示例画面：月光下人渐变为狼/能量包裹后蜕变新形态
- 导演意图：用形态的剧变外化角色的蜕变或失控
- 常用组合：变身前痛苦(微表情#22) → SC-1002变形过程 → 新形态亮相
- 首帧态→尾帧态：原形态 → 新形态(供切新形态全身/反应)
- 风险提示：AI连续变形一致性极难，宜分阶段+遮挡(光/烟/转身)+慢放；可拆首尾两形态生成
- 推荐时长：2–5秒
- 适配题材：奇幻/恐怖/超英/科幻/神话
- 视觉关键词：#变身 #变形 #形态转换 #蜕变
- AI生成提示词：`transformation/morph effect, body/object reshaping, energy envelope, creature transformation, glowing, cinematic`
- 适配视频模型：可灵>即梦（变形一致性难，宜遮挡/慢放）
- 声音音效线索：骨骼变形音/能量嗡鸣+痛吼或低吼
- 🔗组装来源：微表情#22痛苦+灯光(能量光)+运镜SC-203环绕/SC-201缓推

- 光线与色彩：传送门能量光(蓝白漩涡/金色光环/裂缝光)

## SC-1007 时间静止/时停
- 镜头分类：特效 / 时间静止
- 景别与机位：全景/中景，机位缓移穿行于静止的世界
- 焦段建议：35–50mm
- 核心目的：呈现"时间停止、唯一行动者"的奇观——万物凝固，一人自由
- 镜头轨迹：缓移/环绕穿行于凝固的场景，唯一行动者活动
- 画面变化：所有人/物完全静止凝固(空中悬停的水珠/定格的人)，行动者正常移动
- 主体关系：时停者=掌控者，凝固世界=被掌控的舞台
- 情绪效果：超现实、掌控、孤独、诡异、上帝般、力量
- 节奏属性：凝滞中的流动型(反差)
- 光线与色彩：可冷调/去饱和强化"凝固"的诡异
- 适用场景：超能时停、子弹悬停、危机中的从容、时间魔法
- 不适用场景：常规叙事
- 经典示例画面：行动者从凝固的人群与悬停的水珠间穿行
- 导演意图：用"万物静止、一人自由"制造掌控时间的极致奇观
- 常用组合：时停启动 → SC-1007穿行凝固世界(布置/取物) → 时间恢复(突变)
- 首帧态→尾帧态：世界凝固，行动者移动 → 时间恢复(供切常速)
- 风险提示：背景人/物"完全静止"而主体动，AI需明确"everything frozen except subject"，较难，宜简化背景
- 推荐时长：3–6秒
- 适配题材：超英/奇幻/科幻/悬疑
- 视觉关键词：#时间静止 #时停 #万物凝固 #唯一行动者
- AI生成提示词：`time freeze, everything frozen still (suspended water drops, frozen people), only one subject moving through, eerie, cinematic`
- 适配视频模型：可灵（高难，需明确，简化背景）
- 声音音效线索：环境音骤然消失/低频嗡鸣+行动者脚步清晰+恢复时声浪涌回
- 🔗组装来源：运镜SC-205穿行(凝固世界)+灯光(去饱和)+情绪SC-613诡异
