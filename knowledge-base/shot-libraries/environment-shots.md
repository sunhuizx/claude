## SC-901 自然风光定场全景
- 镜头分类：环境 / 自然定场
- 景别与机位：大远景，机位高/远，山川河海等自然地貌为主
- 焦段建议：广角16–35mm（纳入壮阔地貌）
- 核心目的：交代自然环境，建立时空与氛围，制造壮阔或宁静
- 镜头轨迹：静止/缓移/航拍掠过
- 画面变化：自然元素动态(云/水/草浪/光影)让画面有呼吸
- 主体关系：无人或人渺小，自然即主角
- 情绪效果：壮阔、宁静、史诗、渺小、敬畏、自由
- 节奏属性：呼吸式停顿，给观众安顿
- 光线与色彩：自然光(黄金/蓝调最佳)，大色块氛围
- 适用场景：开场、转场、交代地理、史诗/公路/自然纪录
- 不适用场景：紧凑对话、需聚焦人物
- 经典示例画面：晨雾中的群山/金色草原/壮阔海岸
- 导演意图：用自然之大开篇，奠定影片的格局与气质
- 常用组合：自然定场 → 切入人物中景/航拍掠过(SC-208)
- 首帧态→尾帧态：自然全貌，元素流动(供切入主体)
- 风险提示：缺焦点易平淡；AI自然元素动态需明确(云/水流动)
- 推荐时长：3–8秒
- 适配题材：史诗/自然/公路/文艺/冒险
- 视觉关键词：#自然定场 #壮阔风光 #大远景 #氛围
- AI生成提示词：`establishing shot of natural landscape, mountains/river/sea, golden hour, drifting clouds, vast and serene, cinematic 4k`
- 适配视频模型：可灵/Veo/Luma(自然航拍强)>即梦
- 声音音效线索：自然环境音(风/水/鸟)+氛围配乐
- 🔗组装来源：景别SC-103定场/SC-301大远景+灯光SC-13黄金时刻+运镜SC-208航拍

## SC-902 城市天际线
- 镜头分类：环境 / 城市定场
- 景别与机位：大远景，机位高(楼顶/航拍)，城市建筑群天际线
- 焦段建议：广角或长焦压缩(密集楼群)
- 核心目的：交代都市环境，制造繁华、冷峻、压迫或孤独的城市气质
- 镜头轨迹：静止/航拍掠过/延时
- 画面变化：车流/人流/光影/云移，城市的"脉动"
- 主体关系：城市即主角，个体隐于钢铁森林
- 情绪效果：繁华、冷峻、压迫、孤独、现代、欲望
- 节奏属性：定场停顿或延时流动
- 光线与色彩：日景通透/夜景霓虹灯火/黄昏暖金
- 适用场景：都市剧开场、转场、交代城市、繁华或冷峻基调
- 不适用场景：田园/古装/聚焦个人
- 经典示例画面：黄昏俯瞰摩天楼群天际线
- 导演意图：用城市天际线定义现代都市的繁华与疏离
- 常用组合：城市天际线 → 推/切入某栋楼/某个体(从城市到人)
- 首帧态→尾帧态：城市全貌(供切入具体地点/人物)
- 风险提示：AI密集楼群易畸形，长焦压缩或夜景灯火规避
- 推荐时长：3–8秒
- 适配题材：都市/犯罪/商战/爱情/科幻
- 视觉关键词：#城市天际线 #都市定场 #繁华冷峻 #摩天楼
- AI生成提示词：`city skyline establishing shot, dense skyscrapers, aerial or rooftop view, dusk golden light or neon night, urban, cinematic 4k`
- 适配视频模型：可灵/Veo>即梦/Luma
- 声音音效线索：城市底噪(车流/远处喧嚣)+都市配乐
- 🔗组装来源：景别SC-301大远景+运镜SC-208航拍/SC-234延时+灯光SC-21霓虹(夜)

## SC-903 室内空间定场
- 镜头分类：环境 / 室内定场
- 景别与机位：全景，机位固定或缓移，交代室内空间布局与氛围
- 焦段建议：广角24–35mm（纳入室内全貌）
- 核心目的：交代室内场景的空间、陈设、氛围，建立场景基调
- 镜头轨迹：静止/缓推/缓摇环视
- 画面变化：空间陈设静态，可有自然光影/帘动
- 主体关系：空间即主角，暗示居住者的身份/状态
- 情绪效果：温馨/冷清/压抑/奢华/凌乱，由陈设传递
- 节奏属性：定场停顿型
- 光线与色彩：场景光(窗光/灯光/烛光)定调氛围
- 适用场景：进入新场景、交代居所、空间氛围、人物登场前
- 不适用场景：户外大场面、需聚焦表情
- 经典示例画面：缓推进入凌乱/奢华的房间交代主人状态
- 导演意图：用空间陈设"未见其人先知其人"
- 常用组合：室内定场 → 人物入画/切人物中景；缓推入室(SC-220)
- 首帧态→尾帧态：室内空间全貌(供人物入画或切中景)
- 风险提示：陈设要有信息(暗示人物)；AI室内透视/物件一致性
- 推荐时长：3–7秒
- 适配题材：剧情/悬疑/家庭/犯罪/年代
- 视觉关键词：#室内定场 #空间陈设 #场景氛围 #未见其人
- AI生成提示词：`interior establishing shot, room layout and decor, window/lamp light setting mood, wide angle, static or slow push, cinematic`
- 适配视频模型：可灵>即梦>Runway
- 声音音效线索：室内环境音(钟表/电器/窗外)+氛围底噪
- 🔗组装来源：景别SC-103定场+灯光SC-18窗光/#30暖调+运镜SC-220缓推入室

## SC-904 天气氛围镜
- 镜头分类：环境 / 天气氛围
- 景别与机位：任意景别，捕捉雨/雪/雾/风暴/雷电的天气氛围
- 焦段建议：视内容（广角天气全貌/特写雨滴雪花）
- 核心目的：用天气营造强烈情绪氛围——雨的忧郁、雪的纯净、雾的诡秘、风暴的危机
- 镜头轨迹：静止/缓移，天气元素本身在动
- 画面变化：雨幕/飘雪/翻雾/狂风/闪电等天气动态
- 主体关系：天气即情绪，环境与人物心境共振
- 情绪效果：雨=忧郁/洗涤；雪=纯净/孤寂；雾=诡秘/迷茫；风暴=危机/暴怒
- 节奏属性：氛围流动型
- 光线与色彩：天气定调(雨夜冷蓝/雪天灰白/雾天朦胧/风暴压抑)
- 适用场景：情绪渲染、转场、危机预兆、以天气喻心境
- 不适用场景：需晴朗明快/与情绪不符时
- 经典示例画面：雨幕中的街道/漫天飞雪/翻涌浓雾
- 导演意图：让天气替人物说出未言的情绪——天人感应
- 常用组合：天气氛围空镜 → 切入雨/雪中的人物
- 首帧态→尾帧态：天气氛围流动(供切入人物或转场)
- 风险提示：天气元素动态AI需明确(rain/snow falling)；与剧情情绪要呼应
- 推荐时长：2–6秒
- 适配题材：文艺/悲剧/悬疑/爱情/灾难
- 视觉关键词：#天气氛围 #雨雪雾 #风暴 #以天喻情
- AI生成提示词：`weather atmosphere shot, heavy rain/falling snow/rolling fog/storm, moody tone, environmental emotion, cinematic`
- 适配视频模型：可灵>即梦>Luma
- 声音音效线索：天气音(雨声/风声/雷声)+氛围配乐
- 🔗组装来源：灯光SC-16阴天/#17月光/#28体积光雾+情绪库(对应情绪)+SC-123氛围空镜

## SC-905 时间/光线变化镜
- 镜头分类：环境 / 时间光线
- 景别与机位：全景/大远景，捕捉特定时间段的光线氛围
- 焦段建议：广角为主
- 核心目的：用特定时段的光(黎明/黄金时刻/黄昏/蓝调/深夜)定义时间与情绪
- 镜头轨迹：静止/延时(时间流逝)
- 画面变化：光线/天色/影子随时间变化(延时尤明显)
- 主体关系：光即时间即情绪，时段决定基调
- 情绪效果：黎明=希望；黄金时刻=温暖浪漫；黄昏=怀旧；蓝调=忧郁；深夜=孤独/危险
- 节奏属性：定场停顿或延时流动
- 光线与色彩：该时段标志性光色(黄金暖金/蓝调深蓝/夜黑+灯火)
- 适用场景：交代时间、情绪定调、时间流逝、一天的起止
- 不适用场景：需中性无时间感时
- 经典示例画面：黎明微光中的城市/黄金时刻的田野/蓝调时分的街道
- 导演意图：用光的"时辰"给场景定情绪基调
- 常用组合：时间光线定场 → 切入该时段的人物/事件；延时表现时间流逝
- 首帧态→尾帧态：特定时段光线(供切入人物或延时转夜)
- 风险提示：时段光色要准确；延时需真质感(光影流动)
- 推荐时长：3–8秒
- 适配题材：通用/文艺/爱情/公路/剧情
- 视觉关键词：#时间光线 #黄金时刻 #蓝调 #黎明黄昏
- AI生成提示词：`time-of-day lighting shot, dawn/golden hour/dusk/blue hour/night, signature color of the hour, atmospheric, cinematic`
- 适配视频模型：可灵/即梦>Luma>Veo
- 声音音效线索：该时段环境音(晨鸟/暮蝉/夜虫)+氛围配乐
- 🔗组装来源：灯光SC-13黄金时刻/#14蓝调/#17月光+运镜SC-234延时+景别SC-301

## SC-907 地标识别镜
- 镜头分类：环境 / 地标识别
- 景别与机位：全景/大远景，标志性建筑/地标充满画面或居中
- 焦段建议：广角(地标+环境)或长焦(突出地标)
- 核心目的：用知名地标瞬间交代地理位置(城市/国家/特定场所)
- 镜头轨迹：静止/航拍环绕(SC-236)/缓推
- 画面变化：地标为主，可有环境动态(人流/车流/光影)
- 主体关系：地标即"地点名片"，瞬间定位故事发生地
- 情绪效果：识别、定位、地域感、宏伟、旅程
- 节奏属性：定场停顿型
- 光线与色彩：突出地标的标志性光色(日景/夜景灯光)
- 适用场景：交代故事发生城市/国家、旅程到达、地域切换
- 不适用场景：架空/无需定位的场景
- 经典示例画面：埃菲尔铁塔/外滩/长城等地标定场
- 导演意图：一个地标=一句"故事在这里发生"
- 常用组合：地标识别 → 切入该地的人物/街道(从地标到具体)
- 首帧态→尾帧态：地标全貌(供切入具体场景)
- 风险提示：地标特征要准确可辨；AI知名地标可能失真，宜参考图
- 推荐时长：2–6秒
- 适配题材：旅行/都市/谍战/爱情/公路
- 视觉关键词：#地标 #地点名片 #识别定位 #地域感
- AI生成提示词：`landmark establishing shot, iconic recognizable building/monument, wide or aerial, day or night lit, locating the story, cinematic`
- 适配视频模型：可灵/Veo>即梦（地标用参考图更准）
- 声音音效线索：当地环境音+地域特色配乐
- 🔗组装来源：景别SC-301大远景+运镜SC-236航拍环绕+作定位用

## SC-908 环境空镜细节
- 镜头分类：环境 / 空镜细节
- 景别与机位：特写至中景，捕捉环境中的诗意细节(无人物)
- 焦段建议：85mm/微距(细节)或35mm(小景)
- 核心目的：用环境细节(雨打窗/落叶/烛火/钟摆)营造氛围、隐喻、调节奏
- 镜头轨迹：静止/极缓移，细节本身在动
- 画面变化：单一细节的微动(水滴/火苗/摇曳/光斑)
- 主体关系：细节即情绪载体，以小见大、以物喻情
- 情绪效果：诗意、留白、隐喻、宁静、时间感、余韵
- 节奏属性：呼吸式停顿，情绪沉淀
- 光线与色彩：质感光突出细节，氛围色调
- 适用场景：转场、情绪间隙、以景喻情、章节呼吸、时间暗示
- 不适用场景：需推进情节/信息的关键节点
- 经典示例画面：雨珠沿窗滑落/烛火摇曳/秋千轻晃
- 导演意图：用一个安静的细节让观众"喘息"并感受未言的情绪
- 常用组合：情绪戏 → 环境空镜细节(沉淀) → 下一场；转场过渡
- 首帧态→尾帧态：细节微动(供叠化/切入新场)
- 风险提示：滥用拖节奏；细节须与前后情绪呼应
- 推荐时长：2–5秒
- 适配题材：文艺/悬疑/爱情/剧情
- 视觉关键词：#环境空镜 #诗意细节 #以物喻情 #留白
- AI生成提示词：`environmental detail cutaway, rain on window/flickering candle/swaying object, macro or small scene, poetic mood, cinematic`
- 适配视频模型：可灵>即梦>Midjourney(质感)
- 声音音效线索：放大的细节音(雨滴/火苗/钟摆)+抒情配乐
- 🔗组装来源：景别SC-112道具空镜/SC-123氛围空镜+灯光(质感光)

## SC-909 街道市井生活
- 镜头分类：环境 / 街市生活
- 景别与机位：中景/全景，捕捉街道、市集、市井的烟火气
- 焦段建议：35–50mm（生活感纵深）
- 核心目的：呈现街道/市集的市井烟火气、生活质感与地域风情
- 镜头轨迹：静止/横移/缓移穿行
- 画面变化：人来人往、摊贩叫卖、车水马龙的生活流动
- 主体关系：市井群像作背景，烟火气即主角，主角可融入
- 情绪效果：烟火气、生活质感、热闹、地域风情、平凡温暖
- 节奏属性：生活流动型
- 光线与色彩：自然光/市井杂光，温暖生活质感

## SC-932 极简留白环境镜
- 镜头分类：环境 / 极简留白
- 景别与机位：全景/大远景，大面积纯色/负空间构成画面，主体(人物/物件)占比极小，机位平或略高
- 焦段建议：广角24–35mm（最大化留白空间）
- 核心目的：用大面积纯色/负空间制造视觉喘息、东方留白美学或极简主义的情绪张力
- 镜头轨迹：完全静止或极缓微移(几乎不可察觉)
- 画面变化：画面中大面积纯色背景(雪原白沙/天空/单色墙壁/水面)，极小的主体(孤树/单人/孤舟/一缕烟)微动即成为全部焦点
- 主体关系：负空间(留白)=视觉与情绪的容器，微小主体因留白而获得巨大的情绪重量
- 情绪效果：空寂、宁静、孤独、禅意、极简、纯粹、呼吸、自由、无限
- 节奏属性：极静止的呼吸留白型
- 光线与色彩：大面积低饱和或纯色(雪白/沙漠金/天空蓝灰/阴天灰白)，极简配色(单色/双色)，柔和自然光
- 适用场景：情绪沉淀、视觉喘息、转场呼吸、东方美学、禅意、极简风格、结局留白
- 不适用场景：信息密集/动作/需复杂场景
- 经典示例画面：茫茫雪原上一棵孤树占据画面1/20；无垠沙漠中一行脚印延伸至天边；灰白天空中一羽飘落
- 导演意图：用"少即是多"——让留白替画面说话，观众的情绪在负空间中自由填充
- 常用组合：情绪高潮 → 极简留白(沉淀)→ 下一场淡入；或作为开场/终场留白
- 首帧态→尾帧态：大面积留白+微小主体微动(供淡出或切入新场景)
- 风险提示：AI渲染大面积纯色区域时易出现色带/噪点不均匀，需"clean gradient, noise-free"提示；微小主体的姿态/运动要精确以免成为画面瑕疵；过简可能被认为是"未完成"
- 推荐时长：3–8秒
- 适配题材：文艺/禅意/极简/广告/东方美学/纪录片
- 视觉关键词：#极简留白 #负空间 #东方美学 #少即是多

- 声音音效线索：极简寂静(或单音/风声/远处一声鸟鸣)+留白般的静默+若有若无的配乐

## SC-933 超现实幻境镜
- 镜头分类：环境 / 超现实幻境
- 景别与机位：大远景/全景，超现实地貌与物理规律——浮空岛群/倒置城市/液态天空/几何抽象空间
- 焦段建议：广角16–24mm（纳入超现实奇观的规模与荒诞）
- 核心目的：利用AI不受物理规律限制的想象力，创造现实无法拍摄的超现实幻境——仅凭想象力驱动的环境奇观
- 镜头轨迹：漂移穿越超现实空间 / 环绕浮空奇观 / 空间扭曲中推进——镜头运动本身也可超现实
- 画面变化：违背物理的空间元素——漂浮碎裂的大地、流动的星空、倒流的瀑布、几何分形地貌、色彩非现实的植被、M.C.Escher式矛盾空间
- 主体关系：环境即想象力本身——物理规律被悬置，视觉逻辑由情绪与诗意主导，无人类参照系
- 情绪效果：超现实、梦境、迷幻、惊叹、不安、诗意、想象力的极致自由
- 节奏属性：漂移流动或违反重力的节奏型
- 光线与色彩：不受自然光限制——多光源/非欧几里得光照/色彩从情绪出发(紫色沙漠/金色海洋/负片天空)
- 适用场景：奇幻/超现实/梦境段落、心理世界外化、想象力宣言、艺术短片、哲学隐喻
- 不适用场景：写实叙事/纪录/需要物理可信度
- 经典示例画面：破碎的大地碎片漂浮于紫色星空中，每片碎土上长着发光的树；瀑布从下往上倒流进天空
- 导演意图：让AI的想象力"被解放"——不限于物理规律，创造观众从未见过的视觉奇观
- 常用组合：现实场景 → 过渡到超现实幻境(SC-933)→ 梦境/心理世界展开(SC-719)；接奇幻异世界(SC-919)作更狂放的升级
- 首帧态→尾帧态：超现实奇观展开 → 深入幻境或拉回现实(供切人物或心理叙事)
- 风险提示：超现实≠乱画——需有内在视觉逻辑/情绪脉络否则沦为混乱；AI无约束时易生成不可用的随机噪点需"surreal but coherent, intentional surrealism"引导；几何矛盾空间(AI弱项)需精确Prompt描述

- 适配题材：奇幻/超现实/心理/艺术/实验影像
- 视觉关键词：#超现实幻境 #违背物理 #想象力自由 #AI无约束
- AI生成提示词：`surreal dreamscape environment, impossible physics, floating fragmented land with glowing trees in purple nebula sky, waterfall flowing upward, intentional surrealism, coherent dream logic, breathtaking, cinematic 4k`
